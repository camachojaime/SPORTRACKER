# SPORTRACKER


Pasos a seguir para comprobar la funcionalidad del BOT:

  1º  Se deben descargar los archivos Sportracker.py y leerAPI.py, y guardar en la misma carpeta
  
  
  2º  Deberemos tener python3 instalado y las siguientes dependencias:
    
    Request --> pip install request
    
    Python-Telegram-Bot --> pip install python-telegram-bot==13.7
    
  
  3º Después debe ejecutar el archivo Sportracker.py
  
    python3 Sportracker.py
  
  
  4º Abrir bot:
    
    Opción 1:
    Buscar el sigueinte usuario en Telegram: @sportrackerbot
    
    Opción 2:
    https://web.telegram.org/z/#6137289929
    
    Opción 3: Escanear el siguiente QR
![SportrackerQR_pequeña](https://user-images.githubusercontent.com/72512889/234628658-b14f92ec-87e7-43a9-96ca-5d6c00bce025.jpg)

  
  
  5º Utilice uno de los siguientes comandos:
      
    /help - Muestra todos los comandos disponibles
    /command - Muestra todos los comandos disponibles
    /start - Muestra todos los comandos disponibles

    /ultimaCarrera - Muestra el resultado de la ultima carrera
    /proximaCarrera - Muestra los horarios de los eventos de la proxima carrera
    /verClasificacionPilotos - Muestra la clasificacion del mundial de pilotos
    /verClasificacionConstructores - Muestra la clasificacion del mundial de constructores
    
    
# LandingPageISI


Pasos a seguir para visualizar la landing page de nuestro proyecto:

  1º  Instalar en visual studio code la extension de live server para poder visualizar la pagina
  
  2º  Una vez hecho el paso anterior descargar el repositorio y abrilo con visual studio code
  
  3º  Despues hacemos click derecho sobre el fichero .html y abrimos con live server. Ya podemos visulizar la landing page.
